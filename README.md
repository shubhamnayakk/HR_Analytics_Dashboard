# 📊 HR Analytics Power BI Dashboard

## Overview
This project focuses on analyzing employee data using Power BI to uncover workforce trends, track performance metrics and generate actionable HR insights.

---

## Objectives
- Analyze employee performance and productivity
- Measure employee attrition and retention
- Identify workforce distribution across tenure groups
- Evaluate recruitment source effectiveness
- Generate insights for HR decision-making

---

## Key Analysis Performed

### 1. Employee Performance Classification
Classified employees into Excellent, Average and Poor categories based on Daily Error Rate and 90-days Complaints.

### 2. Attrition Analysis
Measured total exits and calculated attrition percentage to evaluate workforce turnover.

### 3. Tenure Distribution Analysis
Analyzed employee distribution across different tenure brackets to understand workforce stability.

### 4. Gender Distribution Analysis
Evaluated gender-wise employee distribution for diversity insights.

### 5. Recruitment Source Analysis
Identified effectiveness of different hiring channels such as referrals, job portals and advertisements.

### 6. Performance Score Analysis
Analyzed distribution of employees across different performance rating categories.

---

## 🛠️ Tech Stack
- Power BI
- Excel
- DAX (Data Analysis Expressions)
- Data Modeling

---

## 📂 Dataset
The dataset consists of employee-level data including:
- Employee ID
- Department and Manager details
- Employee status (Active/Exit)
- Performance scores
- Daily Error Rate and Complaints
- Recruitment source
- Tenure and demographics

---

## How to Use
1. Download the .pbix file from the repository  
2. Open it using Power BI Desktop  
3. Use slicers to filter by Department, Manager and Status
4. Explore the dashboard to analyze insights  

---

## Key Insights
- A large portion of employees fall under long tenure (5+ years)
- Attrition rate highlights potential retention challenges
- Majority employees are categorized under Average performance
- Recruitment is largely driven by referrals and job platforms
- Performance classification helps identify improvement areas
